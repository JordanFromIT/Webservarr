Library Metrics — Layout Options

Six treatments of the same 13 figures. Each option renders twice from identical markup — full-width desktop and a 390 px phone frame — using container queries, so the mobile behaviour shown is real, not a mock. Numbers are always Frosted Blue; labels are always Steel Blue. Theme tokens only.

Sectioned Grid + Hero
